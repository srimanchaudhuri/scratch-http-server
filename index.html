scratch-http-server

An HTTP server built from the ground up in C — no frameworks, no libraries, just raw POSIX sockets and the will to understand how the web actually works.

What's inside

🔌
Raw POSIX Sockets

TCP connections from scratch using socket(), bind(), listen(), accept()

📨
HTTP/1.1 Responses

Dynamically built status lines, Content-Type, Content-Length headers

🛤️
URL Routing

Path-based dispatch — visit /name and get a personalised greeting

📄
Static File Serving

Reads HTML files from disk using fopen, fread, and serves them over HTTP

🔁
Persistent Server

Event loop handles multiple sequential connections without restarting

🧹
Clean Memory

Every malloc'd buffer is freed — no leaks, proper socket cleanup

Quick start

# Clone & build
$ git clone https://github.com/srimanchaudhuri/scratch-http-server.git
$ cd scratch-http-server
$ make

# Run the server
$ bin/server

# Open in your browser
→ http://localhost:8080
→ http://localhost:8080/sriman
